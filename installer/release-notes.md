## Install

1. Download **`NxtFlyout-Setup-<version>.exe`** below and run it. No administrator rights and no .NET install needed.
2. Windows may show *"Windows protected your PC"* because the installer is not code-signed. Click **More info → Run anyway**.
3. Leave *"Start NxtFlyout automatically when I sign in"* ticked, finish, and NxtFlyout starts. Its icon is in the notification area (possibly behind the `^` arrow).

Upgrading: just run the new installer. It closes the running copy and keeps your settings.

Prefer not to install? Download **`NxtFlyout-<version>-portable-x64.zip`**, unzip it anywhere and run `NxtFlyout.exe`.

`SHA256SUMS.txt` lists the checksums of both downloads.

Requires Windows 10 version 2004 or later on an x64 PC (ARM64 Windows 11 runs it under emulation). Windows 11 22H2 or later for Mica/Acrylic flyouts.
